Link corto (opcional)

Para mandar un link corto como go.intellishiphn.com/4mb en vez del link largo del transportista.
El dashboard genera un código corto por guía y lo guarda en Firebase; cuando alguien abre https://{{dominio}}/{{código}} lo redirige al link real del transportista. Para que funcione, ese dominio debe apuntar a una página que te dejo lista (redirect.html) — la subes a un repositorio de GitHub Pages (igual que tu RRHH) guardada dos veces, como index.html y como 404.html, y apuntas el subdominio ahí con un registro DNS tipo CNAME. Si dejas este campo vacío, se envía el link largo del transportista normalmente — la app funciona igual de bien sin esto.

Nota: si abres un link corto de prueba y dice "Link no encontrado", es normal — ese código todavía no existe en la base de datos. Primero procesa una guía real desde este dashboard (con el dominio ya guardado aquí) para que el código se cree, y ese link específico sí funcionará.
